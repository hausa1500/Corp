# Acessibilidade + Responsividade
- Prefira elementos HTML semânticos antes de ARIA.
- Dê nome acessível a todo controle.
- Mantenha focus-visible e ordem de tabulação previsível.
- Não dependa apenas de cor para estados.
- Evite overflow horizontal.
- Garanta touch targets confortáveis.
- Teste 320px, 768px, desktop e ultrawide.
- Respeite zoom, fontes do usuário e reduced motion.
