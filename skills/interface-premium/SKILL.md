# Interface Premium
1. Identifique o sistema visual já existente antes de mudar cores ou componentes.
2. Defina uma direção visual específica ao produto.
3. Priorize hierarquia, tipografia, alinhamento, espaçamento e contraste antes de efeitos.
4. Use tokens para cor, espaçamento, raio, sombra e motion.
5. Todo controle deve ter estados coerentes de hover, foco, disabled e loading quando aplicável.
6. Evite excesso de cards, glow, gradientes decorativos e ícones sem função.
7. Preserve dark/light mode quando existirem.
8. Verifique mobile, tablet e desktop.
