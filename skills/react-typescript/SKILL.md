# React + TypeScript
- Evite `any`; prefira tipos explícitos e unions.
- Nunca chame hooks condicionalmente.
- Extraia hooks quando houver lógica reutilizável real.
- Use memoização somente quando houver justificativa.
- Use chaves estáveis em listas.
- Evite estado duplicado que possa ser derivado.
- Preserve contratos públicos de componentes.
- Procure imports mortos, dependências incorretas de hooks e erros assíncronos não tratados.
