# Performance Web
- Remova trabalho desnecessário do caminho crítico.
- Reduza renders e requests duplicadas.
- Use lazy loading com critério.
- Otimize imagens e reserve dimensões para evitar CLS.
- Evite blur e filtros pesados em grandes superfícies animadas.
- Prefira `transform` e `opacity` para motion.
- Faça cleanup de listeners, observers e timers.
- Não adicione dependência grande para problema pequeno.
