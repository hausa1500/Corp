# Entrega Git Segura
- Leia `AGENTS.md` antes de escrever.
- Trabalhe apenas no repositório e branch confirmados.
- Não force-push, rebase ou amend de histórico publicado.
- Nunca inclua `.env`, tokens ou secrets.
- Faça commit pequeno e descritivo.
- Se a branch mudar durante a operação, interrompa em vez de sobrescrever trabalho concorrente.
- Informe arquivos, commit e validação.
- Lovable é apenas preview/deploy explícito.
